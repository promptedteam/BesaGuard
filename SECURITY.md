# Security policy

## Reporting a vulnerability

Please do not disclose an unpatched BesaGuard vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository when available, or contact promptedteam privately through its published GitHub contact channel.

Include the BesaGuard version, Windows version, reproduction steps, expected result, observed result, and whether any untrusted file or link is required. Do not send live malware or personal data unless a safe transfer method has first been agreed.

## Supported version

Only the newest published beta receives fixes. BesaGuard is currently a personal-core beta, not a certified primary antivirus or production isolation boundary.
